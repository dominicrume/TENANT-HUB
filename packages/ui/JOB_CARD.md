# UI Stage (packages/ui)

**1. What comes in?**
React state, domain data models, and user interaction events (clicks, typing, file uploads).

**2. What do you do with it?**
Render interactive, accessible, and responsive visual components (buttons, tables, modals).

**3. What goes out?**
Emitted callback events, rendered DOM nodes, and formatted data presentations.

**4. How do you know the stage is done?**
The component renders without errors, respects responsive breakpoints, fires expected interaction callbacks, and contains zero business logic or direct database queries.
